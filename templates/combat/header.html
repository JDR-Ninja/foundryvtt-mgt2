{{! THE RANGE STRIP. Position in Traveller is not a map: there is ONE BAND PER PAIR of contacts (Core p.165), so the strip is read from the contact selected in the order outwards and every other one is pinned on it. Each cell carries what the band is worth — the attack DM (p.167) and the Thrust a change out of it costs (p.166). Adjacent and Close print a dash for the DM because the book prints none, not because it is zero. The band is the stored state and the kilometres above derive from it; clicking a cell moves the pinned contact, which is the only way a band changes here. Nothing reads the canvas — the distance is typed. }}
